# Kimino C2S MVP Implementation Plan

**Goal:** Read, write and reply through real ActivityPub C2S in a Solid 2 browser.
**Architecture:** Framework-independent event projection and transport, Solid SPA,
real Docker C2S server. Root orchestrates scoped implementers and independent review.
**Tech Stack:** Solid 2 RC, Vite, TypeScript, Vitest, Playwright, LogTape, Sacho, ONI.
**Spec:** `docs/superpowers/specs/2026-09-08-c2s-mvp-design.md`

## Tasks

- [x] Core: `src/activitypub/` tests before implementation. Export
  `ActivityPubClient({actorUrl, token?, fetch?, maxPages?})`, `loadTimeline()`,
  `publishNote(text, replyTo?)`, and `evaluateActivities(activities)`.
  Validate pagination, deterministic ordering, author-only mutations, token
  origin isolation, redirects, and reply addressing with `npm test`.
- [x] Runtime/UI: replace starter with matching Solid 2 DOM/compiler packages.
  Implement connection form, memory-only token, safe content, chronological
  timeline, refresh, compose, reply, failure/retry, and disconnect. Validate
  `npm run typecheck`, `npm run build`, and browser tests.
- [x] Instance: boot pinned ONI via `compose.yaml`, provision reproducibly,
  document auth and local CORS, seed content, verify real C2S reads/writes.
- [x] Integration: add Playwright real-server smoke and UI security tests.
  Run `npm run check` and `npm run test:e2e` against Docker, then independent
  code review and fix confirmed findings.
- [x] Handoff: AGENTS.md, CI, Sacho configuration/fragment and commands in README.
